## 2. Зачем нужен класс

Представьте список из десятков книг. Для каждой нужно помнить название, автора и прочитана ли она. Если хранить всё в отдельных переменных, названия быстро начнут путаться.

Класс помогает описать, какие данные относятся к книге. Каждый созданный экземпляр такого класса — отдельная конкретная книга со своими данными.

Можно думать о классе как о форме для создания похожих объектов: форма описывает, какие поля есть у записи, а каждая запись хранит собственные значения.

## 3. Разбираем пример по строкам

```python
class Book:
    def __init__(self, title, author):
        self.title = title
        self.author = author
        self.is_read = False

first_book = Book("Дюна", "Фрэнк Герберт")
second_book = Book("Матильда", "Роальд Даль")

print(first_book.title)
print(second_book.title)
print(first_book.is_read)
```

- `class Book:` объявляет описание книг. Имя класса принято писать с большой буквы.
- `__init__` запускается при создании каждой новой книги. Пока можно воспринимать его как специальный начальный шаг.
- `self` означает «этот конкретный объект». В теле `__init__` Python передаёт туда создаваемую книгу.
- `self.title = title` кладёт переданное название внутрь именно этой книги.
- `Book(...)` создаёт новый объект. Поэтому `first_book` и `second_book` — две разные книги.
- `is_read` начинается с `False`: ни одна новая книга ещё не отмечена прочитанной.

Код напечатает:

```text
Дюна
Матильда
False
```

**Проверьте себя перед запуском:** какое название напечатает `print(second_book.title)`? Почему изменение `first_book` само по себе не меняет `second_book`?

## 5. Попробуйте изменить состояние

Добавьте после создания первой книги строку:

```python
first_book.is_read = True
```

Теперь выведите `first_book.is_read` и `second_book.is_read`. Предскажите оба результата до запуска программы.

У первой книги будет `True`, а у второй останется `False`. Атрибут принадлежит конкретной книге, поэтому изменение одного объекта не меняет другой.

## 6. Самостоятельная практика

Создайте класс `Book` и две книги из тех, которые вам интересны. Выведите названия обеих книг. Затем отметьте одну прочитанной и убедитесь, что статус второй не изменился.

Перед завершением проверьте:

- у каждой книги есть собственное название;
- у каждой книги есть собственный статус чтения;
- изменение статуса одной книги не меняет статус другой.

Если застряли, пройдите подсказки по порядку:

1. Сначала создайте класс и `__init__` по примеру выше.
2. Проверьте количество параметров при вызове `Book(...)`: нужны название и автор.
3. Убедитесь, что присваивания начинаются с `self.`.
4. Сравните имена переменных: обе книги должны храниться в разных переменных.

## 7. Короткое повторение

Ответьте без кода:

1. `Book` — это описание или конкретная книга?
2. `first_book` — это описание или конкретная книга?
3. Зачем в `__init__` нужен `self`?

**Ответы:** `Book` — класс, описание; `first_book` — конкретный объект, экземпляр; `self` позволяет обратиться к данным именно того объекта, который создаётся или использует метод.

Не нужно заучивать определения слово в слово. Важно уметь показать в коде, где описание, где конкретные книги и почему их состояния независимы.
