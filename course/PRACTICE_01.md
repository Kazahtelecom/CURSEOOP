# Практика 1. Две книги — два отдельных состояния

**Неделя:** 1  
**Продолжительность:** 60 минут  
**Перед началом:** пройди [урок 1](LESSON_01.md) или попроси преподавателя ещё раз разобрать класс и объект.  
**Нужно:** Python 3 и редактор кода. Сторонние библиотеки не нужны.

## Цель занятия

К концу практики ты сможешь создать класс Book, создать несколько книг и объяснить на примере, почему изменение одной книги не меняет другую. Не обязательно помнить все термины: важно уметь проследить значения каждой книги.

## 1. Разогрев — 5 минут

Прочитай:

    title = "Дюна"
    is_read = False

Расскажи соседу или преподавателю:

- что хранит title;
- что означает False;
- как бы ты назвал переменную для второй книги.

Если занимаешься один, ответь устно или запиши ответ рядом. Это разминка, а не оценка.

## 2. Собираем класс — 7 минут

Вместе прочитайте пример:

    class Book:
        def __init__(self, title, author):
            self.title = title
            self.author = author
            self.is_read = False

Пока код ничего не печатает. Он описывает, какие данные появятся у каждой новой книги.

Преподаватель задаёт вопросы, ученик показывает ответ прямо в коде:

1. Где написано имя класса?
2. Какие значения нужно передать, чтобы создать книгу?
3. Какую отметку получает новая книга?

**Подсказка:** self.title — место для названия внутри конкретной книги; title справа — значение, переданное при создании.

## 3. Создаём две книги — 13 минут

Добавь к классу строки:

    first_book = Book("Дюна", "Фрэнк Герберт")
    second_book = Book("Матильда", "Роальд Даль")

    print(first_book.title)
    print(second_book.title)
    print(first_book.is_read)
    print(second_book.is_read)

Сначала предскажи результат, а затем запусти программу. Сверь его:

    Дюна
    Матильда
    False
    False

Теперь измени состояние первой книги:

    first_book.is_read = True

Снова предскажи два последних результата. Должно получиться True, затем False: у книг отдельное состояние.

**Если не совпало:** проверь, что изменяешь first_book.is_read, а выводишь состояние первой и второй книги отдельно.

## 4. Добавляем действие — 13 минут

Книгу можно отметить прочитанной. Добавим метод внутрь класса:

    class Book:
        def __init__(self, title, author):
            self.title = title
            self.author = author
            self.is_read = False

        def mark_as_read(self):
            self.is_read = True

Метод — действие, записанное внутри класса. Отступ показывает, что mark_as_read относится к Book.

Вызови метод:

    first_book.mark_as_read()
    print(first_book.is_read)
    print(second_book.is_read)

Ожидаемый результат:

    True
    False

Обсуди: почему вызвали first_book.mark_as_read(), а не просто Book.mark_as_read()? Метод меняет состояние конкретного объекта, поэтому его вызывают у конкретной книги.

## 5. Найди ошибку — 10 минут

Для каждого примера сначала предскажи, что пойдёт не так, затем исправь код.

**Ошибка A**

    class Book:
        def __init__(self, title, author):
            title = title
            self.author = author
            self.is_read = False

Создай книгу и попробуй прочитать first_book.title. Название не сохранилось внутри книги: в строке присваивания забыли self.

**Ошибка B**

    class Book:
        def __init__(self, title, author):
            self.title = title
            self.author = author
            self.is_read = False

        def mark_as_read():
            self.is_read = True

В методе не объявлен параметр self. Добавь его первым: def mark_as_read(self):.

**Напоминание:** увидеть сообщение об ошибке и исправить код — обычная часть программирования.

## 6. Самостоятельная задача — 8 минут

Создай третью книгу, которая тебе интересна. Затем:

1. Выведи её название.
2. Вызови mark_as_read() только у неё.
3. Выведи статусы всех трёх книг.
4. Объясни, почему статусы могут различаться.

**Подсказки по очереди:**

1. Для новой книги нужны название и автор.
2. Сохрани результат вызова Book(...) в новую переменную.
3. Вызови метод через эту переменную: имя_книги.mark_as_read().

### Один вариант решения

    third_book = Book("Хоббит", "Дж. Р. Р. Толкин")
    third_book.mark_as_read()

    print(first_book.is_read)
    print(second_book.is_read)
    print(third_book.is_read)

Если первую книгу ты уже отмечал в упражнении, результат может быть True, False, True. Это ожидаемо: программа хранит текущее состояние объектов.

## 7. Выходной билет — 4 минуты

Ответь своими словами:

1. Что описывает Book?
2. Что такое first_book?
3. Какое состояние изменит second_book.mark_as_read()?

**Самопроверка:** Book описывает вид книги; first_book — один конкретный объект; вызов метода у second_book изменяет только её статус.

Если третий ответ пока непонятен, повтори упражнение с двумя книгами. К следующей теме перейдём после того, как станет ясно, почему состояние одной книги не меняет другую.
