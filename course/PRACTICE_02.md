## Цель

Создать ReadingList, который хранит книги, умеет добавлять книги и находить непрочитанные. Мы будем собирать решение небольшими шагами и проверять его на примерах.

## 1. Вспоминаем — 5 минут

Скажи, какой объект должен отвечать за каждое действие:

- хранить автора одной книги;
- отметить одну книгу прочитанной;
- хранить все книги;
- найти среди них непрочитанные.

**Подсказка:** первые два действия относятся к Book, последние два — к ReadingList.

## 2. Начинаем с пустого списка — 10 минут

В новый файл скопируй класс Book:

    class Book:
        def __init__(self, title, author):
            self.title = title
            self.author = author
            self.is_read = False

        def mark_as_read(self):
            self.is_read = True

Теперь добавь класс ReadingList:

    class ReadingList:
        def __init__(self):
            self.books = []

Создай список и проверь его:

    reading_list = ReadingList()
    print(reading_list.books)

Должно напечататься:

    []

Это пустой список: пока ни одной книги не добавили.

## 3. Добавляем книги — 10 минут

Внутрь ReadingList добавь метод:

    def add_book(self, book):
        self.books.append(book)

Создай две книги, добавь их в список и проверь количество:

    dune = Book("Дюна", "Фрэнк Герберт")
    matilda = Book("Матильда", "Роальд Даль")

    reading_list.add_book(dune)
    reading_list.add_book(matilda)
    print(len(reading_list.books))

Ожидаемый результат — 2.

**Подсказка:** метод add_book должен быть с отступом внутри класса ReadingList. Вызов reading_list.add_book(...) добавляет книгу в конкретный список.

## 4. Находим непрочитанные — 13 минут

Добавь в ReadingList метод unread_books:

    def unread_books(self):
        result = []
        for book in self.books:
            if not book.is_read:
                result.append(book)
        return result

Проверь, сколько книг вернулось:

    print(len(reading_list.unread_books()))

Пока ожидаемый результат — 2.

Теперь отметь одну книгу прочитанной:

    dune.mark_as_read()
    print(len(reading_list.unread_books()))

Теперь ожидаемый результат — 1.

## 5. Проверяем граничные случаи — 10 минут

Создай второй пустой список и проверь его:

    empty_list = ReadingList()
    print(empty_list.unread_books())

Ожидается пустой список:

    []

Затем добавь одну книгу и убедись, что она появляется в непрочитанных. После mark_as_read() она должна исчезнуть из результата.

Что проверить:

- пустой список не вызывает ошибку;
- новый список действительно пуст;
- добавление книги влияет на тот список, куда её добавили;
- отметка одной книги не меняет статус другой.

## 6. Самостоятельное расширение — 8 минут

Добавь метод unread_count(), который возвращает количество непрочитанных книг.

**Подсказка:** можно вернуть длину списка, который уже создаёт unread_books().

### Один вариант решения

    def unread_count(self):
        return len(self.unread_books())

Проверь его до и после отметки книги прочитанной.

## 7. Выходной билет — 4 минуты
