02　 НОВАЯ ИДЕЯ 5 минут

Когда книг много, нужен порядок

У каждой книги есть название, автор и отметка о прочтении. Если хранить всё в отдельных переменных, их быстро станет трудно держать в порядке.

Класс — описание того, какие данные есть у книги. Объект — одна конкретная книга, созданная по этому описанию.

▤　Представь библиотечную карточку с полями «название», «автор», «прочитана?». Класс описывает карточку, объект — заполненную карточку конкретной книги.
03　 СМОТРИМ ПО СТРОКАМ 8 минут

Создаём два отдельных объекта

Здесь есть новые слова. Разберём их по одному — запоминать всё сразу не нужно.

class Book:
    def __init__(self, title, author):
        self.title = title
        self.author = author
        self.is_read = False

first_book = Book("Дюна", "Фрэнк Герберт")
second_book = Book("Матильда", "Роальд Даль")

print(first_book.title)
print(second_book.title)
  1. class Book говорит Python: «вот описание книги».
  2. __init__ задаёт начальные данные при создании книги.
  3. self означает «именно эта книга». Поэтому self.title — название конкретной книги.
  4. Каждый вызов Book(...) создаёт отдельный объект со своими значениями.

06　 ЗАПОМНИ ГЛАВНОЕ 2 минуты

Три мысли на сегодня

  • Класс описывает данные похожих объектов.
  • Объект — один конкретный экземпляр со своими данными.
  • self помогает обратиться к данным именно этого объекта.

Не нужно учить определения наизусть. Достаточно уметь показать класс и две отдельные книги в примере.
