**Текущая роль:** Исполнитель / Координатор  
**Дата:** 2026-10-07

## Запрос владельца и разрешение

Владелец попросил создать публичный GitHub-репозиторий CURSEOOP, затем подтвердил вход в GitHub и дал прямое разрешение: «да публикуй». Он также разрешил самостоятельно определить содержимое `.gitignore`.

## Результат и критерии

- Создать публичный репозиторий `Kazahtelecom/CURSEOOP`.
- Публиковать подготовленный проектный снимок и документы, не отправляя прежнюю локальную историю с личным адресом автора.
- Исключить таблицу с оценками и сторонние изображения, права на публикацию которых не установлены.
- Проверить видимость репозитория и наличие ключевых файлов.

## Границы

Публикация исходников и документов не означает публикацию или запуск сайта. Веб-прототип остаётся замороженным. Условия лицензии не выбирались.

## Ограничения и следующий шаг

Публикация создана отдельной свежей историей-снимком через GitHub API; текущий локальный репозиторий не подключён к ней как remote и его история не отправлялась. Владелец просматривает публичный репозиторий и сообщает о необходимости поправок. Отдельно выбрать лицензию, если владелец хочет задать условия использования.
